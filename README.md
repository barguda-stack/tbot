# Торговый бот для Московской биржи (Tinkoff Invest)

Это базовый каркас для создания торгового бота для работы на Московской бирже (MOEX) с использованием [Tinkoff Invest Python API v2](https://github.com/Tinkoff/invest-python).

## Возможности
- Подключение к Tinkoff Invest API (v2).
- Автоматический запрос баланса портфеля для обеспечения торговли только на собственные средства (без использования кредитного плеча).
- Непрерывный торговый цикл, подготовленный для внедрения вашей собственной торговой стратегии.
- Предварительно настроенный шаблон GitHub Actions для автоматического развертывания (деплоя) при слиянии изменений в GitHub.

## Установка и запуск

1. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка конфигурации**
   - Скопируйте файл `.env.example` в `.env`:
     ```bash
     cp .env.example .env
     ```
   - Получите ваш токен Tinkoff API в [настройках профиля](https://www.tinkoff.ru/invest/settings/).
   - Вставьте токен в переменную `TINKOFF_TOKEN` внутри вашего файла `.env`.

3. **Локальный запуск бота**
   ```bash
   python main.py
   ```

## Разработка и кастомизация

Основная логика находится в файле `main.py`. Обратите внимание на функцию `trading_loop`. 
Именно здесь вам следует реализовать свою торговую стратегию (например, получение исторических свечей, расчет скользящих средних, индикатора RSI и отправка заявок на биржу).

## CI/CD и Автоматическое развертывание

Когда вы редактируете код прямо в веб-интерфейсе GitHub и нажимаете кнопку "Commit" / "Применить", вы можете настроить свой сервер на автоматическое скачивание нового кода и перезапуск бота.

1. Перейдите в файл `.github/workflows/deploy.yml`.
2. Раскомментируйте блок `appleboy/ssh-action`.
3. В настройках вашего репозитория на GitHub (Settings -> Secrets and variables -> Actions) добавьте следующие секреты:
   - `HOST`: IP-адрес вашего сервера.
   - `USERNAME`: Имя пользователя SSH на вашем сервере.
   - `SSH_PRIVATE_KEY`: Ваш закрытый SSH-ключ для доступа к серверу.
4. Обновите скрипт внутри `deploy.yml`, указав правильный путь к вашему боту на сервере и команду для его перезапуска (например, `systemctl restart mybot`).
